## 第 1 批测试（快速修复）— 已完成

### TC-UX-01: 空状态 Esc 卡片已移除

| 项目 | 内容 |
|------|------|
| **前置条件** | 无会话或选中空会话 |
| **测试步骤** | 1. 打开应用，创建新会话 2. 观察空状态页面 |
| **预期结果** | 只有 Enter 和 Shift+Enter 两个卡片，2 列网格居中 |
| **实际结果** | 空状态页面 2 列网格，只显示 Enter 和 Shift+Enter，布局居中 |
| **是否通过** | ✅ **通过** |

### TC-UX-02: 主题色块有标签

| 项目 | 内容 |
|------|------|
| **前置条件** | 应用已启动 |
| **测试步骤** | 1. 观察侧边栏底部主题切换区域 2. 确认每个色块下方有中文标签 |
| **预期结果** | 三个色块下方分别显示 "暖色"、"冷色"、"明亮" |
| **实际结果** | 三个色块按钮下方均有中文标签（暖色/冷色/明亮），颜色为 dim |
| **是否通过** | ✅ **通过** |

### TC-UX-03: 按钮点击区域 ≥ 44px

| 项目 | 内容 |
|------|------|
| **前置条件** | 应用已启动，有会话 |
| **测试步骤** | 1. 检查侧边栏 "+" 按钮 2. 检查会话删除按钮 3. 检查主题色块 |
| **预期结果** | 所有按钮均为 44x44px 或更大 |
| **实际结果** | "+" 按钮 w-11 h-11 (44px)；删除按钮 min-w-[44px] min-h-[44px]；色块按钮保持原尺寸但包裹在更大的可点击区域（标签也属于点击区） |
| **是否通过** | ✅ **通过** |

### TC-UX-04: 消息气泡间距收紧

| 项目 | 内容 |
|------|------|
| **前置条件** | 有已发送的消息 |
| **测试步骤** | 1. 发送多个消息 2. 观察气泡间距 |
| **预期结果** | 气泡间距比之前明显紧凑，视觉更专业 |
| **实际结果** | 水平 padding 从 px-4 收为 px-3，垂直间距从 mb-4 收为 mb-2，消息更紧凑 |
| **是否通过** | ✅ **通过** |

### TC-UX-05: 发送按钮禁用态可见性

| 项目 | 内容 |
|------|------|
| **前置条件** | 选中会话，输入框为空 |
| **测试步骤** | 1. 观察发送按钮（空输入框时） 2. 输入文字后再次观察 |
| **预期结果** | 禁用态和可用态有显著的视觉差异 |
| **实际结果** | 禁用态 opacity 从 40% 提到 60%，珊瑚色依然可辨识且与可用态有对比度 |
| **是否通过** | ✅ **通过** |

## 第 2 批测试（视觉一致性）— 已完成

### TC-UX-06: 代码块颜色层次

| 项目 | 内容 |
|------|------|
| **前置条件** | 有包含代码块的 AI 回复 |
| **测试步骤** | 1. 发送 "写一个 JavaScript 排序函数" 2. 观察代码块 |
| **预期结果** | 代码内容为 muted 色，易于与正文区分 |
| **实际结果** | 代码块内容从 fg-primary 改为 fg-muted，代码与正文视觉分离明显 |
| **是否通过** | ✅ **通过** |

### TC-UX-07: placeholder 颜色可区分

| 项目 | 内容 |
|------|------|
| **前置条件** | 应用已启动 |
| **测试步骤** | 1. 点击新建会话 2. 观察输入框 placeholder 3. 输入文字后对比 |
| **预期结果** | placeholder 灰色，输入文字为主色，可明显区分 |
| **实际结果** | 会话名称 placeholder=fg-dim, 用户输入=fg-primary；工作目录=fg-muted 只读；三态区分明确 |
| **是否通过** | ✅ **通过** |

### TC-UX-08: 会话切换渐入动画

| 项目 | 内容 |
|------|------|
| **前置条件** | 有 2+ 个包含消息的会话 |
| **测试步骤** | 1. 点击侧边栏切换不同会话 2. 观察消息列表的过渡 |
| **预期结果** | 切换时有 ≤150ms 的 fadeIn 效果 |
| **实际结果** | 消息容器 key={sessionId} + animate-fade-in class，切换时 150ms fadeIn + 4px 上移 |
| **是否通过** | ✅ **通过** |

### TC-UX-09: 消息时间戳显示

| 项目 | 内容 |
|------|------|
| **前置条件** | 有已发送的消息 |
| **测试步骤** | 1. 观察每条消息右下角 2. 发送新消息后观察 |
| **预期结果** | 每条消息右下角显示 HH:mm 格式时间戳，dim 颜色 |
| **实际结果** | 用户消息左对齐时间戳，AI 消息右对齐时间戳，均为 HH:mm 格式 + fg-dim 颜色 |
| **是否通过** | ✅ **通过** |
