# 11-input-model-test — 输入区域 + 模型切换 测试

**日期：** 2026-07-29

## 测试内容

1. 输入框显示/隐藏（依赖 sessionId）
2. Enter 发送 / Shift+Enter 换行
3. 空输入禁用发送按钮
4. textarea 自动高度调整
5. 模型下拉选择器（4 个模型）
6. 流式生成中显示 "停止" 按钮
7. Esc 取消当前生成
8. 底部快捷键提示栏

## 测试步骤

1. 未选择会话时，确认输入区不显示
2. 创建会话后，输入区出现，"发送" 按钮灰色
3. 输入文字后 "发送" 按钮变珊瑚色可点击
4. 点击发送，输入区变成 "停止" 按钮 + 输入框 disabled
5. 按 Esc 或在生成中点击停止，恢复可输入状态
6. 切换模型下拉，确认选项切换
7. 多行输入后 textarea 高度增加，超出 200px 限制后不再增加

## 预期结果

- 状态流转正确：空 → 输入中 → 流式生成中 → 恢复
- 发送按钮在无文字时 disabled
- 快捷键提示栏 3 个快捷键常驻显示
- 模型下拉默认 "Sonnet 4.6"

## 实际结果

- 状态流转正确
- 发送后自动清空输入框 + 重置高度
- 快捷键栏右侧显示 Enter/Shift+Enter/Esc（UX-04）
- 模型选择器样式已更新为暖色系（UX-06）
