# 10-chat-view-test — 聊天视图组件 测试

**日期：** 2026-07-29

## 测试内容

1. MessageBubble 组件渲染（用户/AI 气泡）
2. Markdown 渲染（标题、列表、粗体、链接）
3. CodeBlock 语法高亮 + 复制按钮
4. 思考过程折叠/展开
5. 流式加载动画（TypingDots / 脉动光标）
6. ErrorBanner 错误提示（8s 自动消失 + 手动关闭）

## 测试步骤

1. 发送一条消息，观察气泡排列
2. 发送包含代码的消息，检查代码块渲染
3. 复制代码块，确认 "已复制 ✓" 提示
4. 观察 AI 回复中的思考过程折叠功能
5. 发送消息后立即观察 loading 三小点动画
6. 触发错误（如未安装 claude），确认 ErrorBanner 显示

## 预期结果

- 用户气泡右对齐珊瑚色，AI 气泡左对齐暖灰色
- 代码块暗底 + 语言标签 + 复制按钮
- 思考过程默认折叠，点击展开
- 空 AI 气泡显示三小点弹跳动画
- 错误横幅 8 秒后滑出消失

## 实际结果

- 气泡对齐正确，颜色符合暖色暗色方案（UX-06）
- 代码块样式正确，复制功能正常
- 思考过程折叠状态由 thinkingExpanded 控制
- TypingDots 组件在 content 为空且 isStreaming 时显示
- ErrorBanner 带 ⚠️ 图标 + 手动关闭按钮 + 8s 自动消失

## 是否通过

✅ 通过
