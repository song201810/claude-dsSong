## 实现要点

- **文件扫描**：`fs.readdirSync` + `statSync` 递归扫描（maxDepth=3），忽略 `node_modules`、`.git`、隐藏文件
- **触发条件**：输入 `@`（前无字母），后跟可选字母过滤
- **过滤逻辑**：匹配文件名和路径，最多 10 条
- **键盘导航**：↑ ↓ 循环移动高亮，Enter 确认，Escape 关闭
- **插入格式**：`@relative/path` + 空格 + 原文字
- **点击外部关闭**：用 `mousedown` 事件延迟注册处理
