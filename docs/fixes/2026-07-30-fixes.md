# 修复记录 — 2026-07-30

## Fix 1: 启动黑屏 — loadGroups TDZ 导致 React 渲染崩溃

**问题描述**: 添加会话分组功能后，应用启动黑屏，渲染进程崩溃。

**根因**: `src/renderer/src/context/AppContext.tsx` 中 `createSession` 回调（第 168 行）引用了 `loadGroups`，但 `loadGroups` 定义在第 237 行。JavaScript `const` 存在暂时性死区（Temporal Dead Zone），运行时抛出 `ReferenceError: Cannot access 'loadGroups' before initialization`，React 组件树无法渲染，表现为黑屏。

TypeScript 无法检测此问题 — `useCallback` 中的函数体在运行时才执行，编译期不会报错。

**修复方案**: 将 `loadGroups` 的定义从第 237 行移动到 `createSession` 之前（第 168 行之前），消除 TDZ。

**涉及文件**: `src/renderer/src/context/AppContext.tsx`

**验证结果**:
- `npx tsc --noEmit` — 通过
- `npx electron-vite build` — 构建成功
- 应用启动正常，不再黑屏

## Fix 2: 点击新建分组按钮无反应

**问题描述**: 点击侧边栏的 FolderPlus 按钮创建分组时，没有任何反应。

**根因**: 使用 `window.prompt()` 弹窗获取分组名称。在 Electron 的 `contextIsolation: true` 环境中，`prompt()` 可能被阻断或不显示，导致点击按钮后无任何可见反馈。

**修复方案**: 将 `prompt()` 替换为内联输入框——点击按钮后在侧边栏头部下方出现一个输入框，支持 Enter 提交、Escape 取消。与应用的 UI 风格一致（使用 CSS 变量，匹配主题）。

**涉及文件**: `src/renderer/src/components/Sidebar.tsx`

**验证结果**:
- `npx tsc --noEmit` — 通过
- `npx electron-vite build` — 构建成功

## Fix 3: 对话框（浏览器原生）与下拉菜单无响应

**问题描述**: 三处浏览器原生对话框和下拉菜单无响应：
1. GroupHeader 三点菜单按钮点击无反应
2. GroupHeader 删除确认弹窗不出现
3. SessionItem 删除确认弹窗不出现

**根因**: 两个问题叠加：
1. Electron `contextIsolation: true` 环境下 `window.confirm()` 被阻断
2. GroupHeader 下拉菜单用 `absolute` 定位，被父容器 `.overflow-y-auto` 裁剪

**修复方案**:
1. `confirm()` → 内联确认 UI：SessionItem 用两步确认（✕ → 「删除? 确认/取消」），GroupHeader 用 fixed 定位的确认面板
2. GroupHeader 下拉菜单：`absolute` → `fixed` + `getBoundingClientRect()` 计算位置

**涉及文件**: `src/renderer/src/components/GroupHeader.tsx`、`src/renderer/src/components/SessionItem.tsx`

**验证结果**:
- `npx tsc --noEmit` — 通过
- `npx electron-vite build` — 构建成功
