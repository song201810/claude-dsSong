# UI/UX 界面优化 — 验收标准

**日期：** 2026-07-29  
**关联计划：** `docs/superpowers/plans/2026-07-29-ui-ux-optimization.md`  
**关联审计：** `docs/superpowers/specs/2026-07-29-ui-ux-audit.md`

---

## AC-1: 空状态无遗留功能入口 (D3)

- [ ] 空状态页面只有 Enter 和 Shift+Enter 两个快捷键卡片
- [ ] Esc 卡片已移除
- [ ] 布局为中心 2 列，视觉平衡

## AC-2: 主题色块有明确标签 (C5)

- [ ] 三个色块按钮各自下方有中文描述文字
- [ ] 文字颜色为 `text-[var(--fg-dim)]`，字号 10px
- [ ] 当前选中主题的色块有 accent 边框高亮

## AC-3: 所有交互元素满足 44px 最小点击区域 (B4)

- [ ] 侧边栏 "+" 按钮：`min-w-[44px] min-h-[44px]`
- [ ] 会话删除按钮：`w-11 h-11` (44px)
- [ ] 主题色块按钮：`w-11 h-11` (44px)
- [ ] 无小于 44px 的关键交互元素（滚动条除外）

## AC-4: 消息气泡间距紧凑 (B2)

- [ ] 气泡水平 padding 从 `px-4` 收紧为 `px-3`
- [ ] 气泡垂直间距从 `mb-4` 收紧为 `mb-2`
- [ ] 最大宽度 `max-w-[85%]` 保持不变

## AC-5: 发送按钮禁用态可见性 (B5)

- [ ] 禁用态不透明度从 40% 提升为 60%
- [ ] 用户能清晰区分可用与禁用状态
- [ ] 珊瑚色按钮在禁用态下仍有可辨识的暖色调

## AC-6: 代码块视觉层次 (C2)

- [ ] 代码内容颜色为 `text-[var(--fg-muted)]`，不与正文混同
- [ ] 代码块头部和背景与代码内容视觉分离
- [ ] 三套主题下代码块风格一致

## AC-7: placeholder 文字与输入文字可区分 (C3)

- [ ] placeholder 颜色为 `text-[var(--fg-dim)]`
- [ ] 用户输入文字颜色为 `text-[var(--fg-primary)]`
- [ ] 只读字段（工作目录）使用 `text-[var(--fg-muted)]`

## AC-8: 会话切换有视觉反馈 (D4)

- [ ] 切换到不同会话时消息列表有渐入效果
- [ ] 动画时长 ≤ 150ms，不阻塞交互

## AC-9: 消息时间戳可读 (D2)

- [ ] 每条消息右下角显示发送时间
- [ ] 格式为 `HH:mm`
- [ ] 时间戳颜色为 `text-[var(--fg-dim)]`

## AC-10: 全局焦点状态一致 (A1)

- [ ] 所有交互元素在获得焦点时有明显的焦点环
- [ ] 焦点环颜色为 `var(--accent)`
- [ ] 无交互元素完全不可 Tab 到达

## AC-11: SVG 图标替换 Emoji (A2)

- [ ] 机器人 emoji → Bot 图标（lucide-react）
- [ ] 警告 emoji → AlertTriangle 图标
- [ ] 对话 emoji → MessageSquare 图标
- [ ] 所有图标大小统一为 20px，颜色跟随主题变量

## AC-12: 会话独立滚动位置 (C4)

- [ ] 切到不同会话再切回时，恢复上次的滚动位置
- [ ] 新消息到达时仍自动滚动到底部
- [ ] 滚动位置不跨会话污染
